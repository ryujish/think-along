## P2-3 확정 결정 충돌 검증

- 변경 내용: 같은 주제의 서로 다른 확정 결정은 기존 결정을 명시적으로 supersede하지 않으면 저장을 거부한다.
- 테스트 결과: 충돌 ID 반환, 무단 덮어쓰기 차단, 정상 supersede 계약 통과.
- 남은 문제: 자유문장의 의미론적 충돌 분석은 후속 AI 평가 범위다.
- 다음 루프: 자동 라우팅 경계.
