# Think Along — Product Vision v0.1

## 1. 한 문장 비전

> 여러 AI를 사용하지만, 사용자는 단 하나의 AI와 계속 대화하고 있다고 느끼게 한다.

Think Along의 핵심은 AI를 하나 더 만드는 것이 아닙니다.

GPT, Claude, Gemini, Kimi, 로컬 모델 등 이미 좋은 AI들이 있습니다. 문제는 사용자가 AI를 바꿀 때마다 대화와 기억, 작업의 흐름까지 끊어진다는 것입니다.

Think Along은 그 사이에 위치합니다.

```text
             사용자
                │
                ▼
        ┌───────────────┐
        │  THINK ALONG  │
        │               │
        │ 나를 기억하는 │
        │ 하나의 AI     │
        └───────┬───────┘
                │
       ┌────────┼────────┐
       ▼        ▼        ▼
      GPT     Claude   Gemini
       │        │        │
       └────────┼────────┘
                │
           기타 AI...
```

**모델은 바뀌어도 관계와 기억은 바뀌지 않는다.**

이것을 제품의 제1원칙으로 둡니다.

## 2. 우리가 해결하려는 문제

지금 AI를 많이 사용하는 사람에게는 이상한 일이 발생합니다.

오늘 GPT와 2시간 동안 프로젝트를 논의했습니다. 그런데 사용량 제한이 걸립니다. Claude로 이동합니다. 그러면 다시 설명해야 합니다.

> “내가 이런 프로젝트를 만들고 있는데…”

그리고 Claude에서 작업하다 Codex로 이동하면 또 설명합니다. Gemini로 이동하면 또 처음부터입니다.

결국 사용자가 AI들의 기억을 직접 관리하는 역할을 하고 있습니다.

Think Along은 이것을 없애는 제품입니다.

## 3. Think Along의 핵심 철학

앞의 OpenClaw 분석까지 연결해서 보면 가장 중요한 문장은 이것입니다.

> AI가 기억을 소유하지 않는다. Think Along이 기억을 소유한다.

GPT는 Think Along의 두뇌 중 하나일 뿐입니다. Claude도 마찬가지입니다.

```text
                 Think Along
                     │
          ┌──────────┴──────────┐
          │                     │
       MEMORY                CONTEXT
          │                     │
          └──────────┬──────────┘
                     │
                  ROUTER
                     │
       ┌─────────────┼─────────────┐
       ▼             ▼             ▼
      GPT          Claude        Gemini
```

따라서 GPT를 Claude로 교체해도:

- 사용자 기억은 그대로.
- 프로젝트 기억도 그대로.
- 대화도 그대로.
- 결정사항도 그대로.
- 현재 작업도 그대로.

바뀌는 것은 추론을 수행하는 엔진뿐입니다.

이 원칙이 Think Along의 기술적인 해자(moat)가 될 가능성이 있습니다.

## 4. 사용자가 경험해야 하는 제품

Think Along을 열었을 때 이런 화면을 만들고 싶지 않습니다.

```text
Select Provider

○ OpenAI
○ Anthropic
○ Gemini
○ OpenRouter

Model:
GPT-5.6 ▼

Temperature:
0.7
```

이것은 개발자용 AI 클라이언트입니다.

Think Along은 반대여야 합니다.

```text
┌──────────────────────────────┐
│ Think Along                  │
│                              │
│ 어제 FlowPulse 작업          │
│ 계속할까요?                  │
│                              │
│ ┌──────────────────────────┐ │
│ │ 메시지 입력...          ↑│ │
│ └──────────────────────────┘ │
│                              │
└──────────────────────────────┘
```

사용자는 모델이 아니라 자신의 일을 봅니다.

## 5. AI 전환도 사용자에게는 사건이 아니어야 함

예를 들어 내부적으로는:

```text
10:01 GPT
10:04 GPT
10:08 GPT

──── GPT rate limit ────

10:11 Claude
10:14 Claude

──── Claude unavailable ────

10:16 Gemini
```

이렇게 움직여도 사용자 화면에서는:

```text
나
AI

나
AI

나
AI
```

입니다.

필요하면 작은 정보 버튼 정도로 다음 내용을 확인할 수 있게 만들 수 있습니다.

> Claude가 처리함

하지만 기본 경험에서는 provider를 전면에 내세우지 않습니다.

## 6. 그러면 AI 선택 기능은 필요 없는가?

필요합니다. 다만 주인공이면 안 됩니다.

고급 사용자는 다음과 같이 요청할 수 있습니다.

> 이번 코딩 작업은 Claude로 해줘.

또는:

> 이 문제를 GPT와 Gemini 둘 다 검토해줘.

즉 Think Along에는 두 가지가 공존합니다.

### Auto

```text
Think Along
   ↓
가장 적합한 AI 자동 선택
```

### Manual

```text
사용자
 ↓
Claude 지정
```

하지만 어느 쪽을 선택해도 Memory와 Session은 Think Along 소유입니다.

## 7. Think Along의 진짜 핵심 기능 4개

기능을 많이 넣기 전에 이것만 성공시킵니다.

### ① Continuity — 이어진다

어떤 AI를 사용해도 이전 대화를 알고 있습니다.

### ② Memory — 기억한다

단순 chat history가 아닙니다.

- 사용자
- 프로젝트
- 선호
- 결정
- 목표
- 현재 작업

을 기억합니다.

### ③ Routing — 알아서 바꾼다

사용량 제한, 장애, 비용, 작업 특성 등에 따라 AI를 변경합니다.

### ④ Transparency — 필요하면 보여준다

AI 전환을 숨겨서 속이는 제품은 아닙니다.

사용자가 원하면 다음과 같이 확인할 수 있어야 합니다.

```text
이번 응답
Claude Sonnet

전환 이유
GPT 사용량 제한
```

보이지 않는 것과 숨기는 것은 다릅니다.

## 8. 경쟁 제품과 Think Along의 위치

제품 포지셔닝을 명확하게 해야 합니다.

- ChatGPT, Claude, Gemini는 기본적으로 AI 모델 중심 서비스입니다.
- Cline, Continue 같은 제품은 개발 작업 중심 AI 클라이언트에 가깝습니다.
- OpenClaw는 개인 AI 에이전트와 실행 인프라 쪽이 강합니다.

Think Along은 **AI Continuity Layer**가 됩니다.

```text
                USER
                  │
                  ▼
        ┌─────────────────┐
        │   THINK ALONG   │
        │                 │
        │ Identity        │
        │ Memory          │
        │ Context         │
        │ Session         │
        │ Routing         │
        └────────┬────────┘
                 │
      ┌──────────┼──────────┐
      ▼          ▼          ▼
   OpenAI    Anthropic    Google
```

AI 위가 아니라 AI와 사용자 사이에 존재합니다.

## 9. 그래서 이름 Think Along도 의미가 생김

**Think for me**가 아니라 **Think Along**입니다.

사용자가 AI를 바꿀 때마다 새로운 AI에게 자신을 설명하는 것이 아니라, 시간이 지나면서 나와 함께 생각해 온 하나의 존재처럼 느껴지는 것.

이것이 브랜드 철학으로 연결될 수 있습니다.

제품 문구로 발전시키면:

> Different AI. One continuous mind.

또는 한국어로:

> AI는 바뀌어도, 생각은 이어집니다.

두 번째 문장이 Think Along의 핵심을 상당히 잘 표현합니다.

## 10. 반대로 지금 하지 않을 것

제품 비전을 지키려면 하지 않을 것도 명확해야 합니다.

초기 Think Along은:

- AI 모델 자체를 개발하지 않는다.
- ChatGPT 기능을 전부 복제하지 않는다.
- OpenClaw 전체를 복제하지 않는다.
- 거대한 autonomous agent 플랫폼을 만들지 않는다.
- 수십 개의 Skills부터 만들지 않는다.
- AI끼리 토론시키는 화려한 multi-agent 기능부터 만들지 않는다.

MVP의 성공 기준은 훨씬 단순합니다.

> GPT로 대화하다 Claude로 바뀌었는데 사용자가 아무 설명도 다시 하지 않고 자연스럽게 다음 대화를 이어갈 수 있는가?

**YES라면 Think Along v1의 핵심은 성공입니다.**
