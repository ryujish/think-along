# Think Along 프로젝트 현황

- 작성일: 2026-08-24
- 현재 단계: **MVP**

## 1. 코드 개발 상태

Think Along은 현재 로컬 웹에서 직접 사용할 수 있는 **작동하는 MVP** 단계다.

### 구현 완료

- Next.js 16, TypeScript, React 19 기반 웹 UI
- Think → Journey → Insight → Profile 사용자 흐름
- 프로젝트 홈, 새 Thinking, Thinking Detail, 대화 이어가기
- 하나의 `thinkalong_session_id`를 기준으로 한 연속 대화
- 모델을 바꿔도 최근 대화, 결정, 요약을 전달하는 Context Packet
- Provider → Account → Model 구조와 수동 전환
- GPT, Claude, Gemini, Grok, Kimi, OpenCode Zen 연결 화면
- Provider별 API Key 등록, 연결 확인, 하위 모델 선택
- GPT, Claude, Gemini, Grok, Kimi, OpenCode Zen 실제 API 호출 경로
- 대화·Provider·모델·Context 버전 실행 이력 저장
- Decision Memory와 결정 대체 이력
- Journey 타임라인과 Insight 화면
- 현재 대화 전체 Markdown 파일 내보내기
- 확인창을 거친 현재 대화 삭제
- 다크·라이트 화면 모드
- 로컬 파일 기반 JSON 데이터 저장

### 현재 기술적 상태

- P0~P3 내부 기능 계약과 기본 구현은 완료됐다.
- 프로덕션 빌드와 TypeScript 검사를 통과한다.
- 현재 `http://127.0.0.1:3000`에서 로컬 미리보기로 검증 중이다.
- API Key는 현재 브라우저에 저장하며 서버 데이터와 Context Packet에는 포함하지 않는다.
- 사용자가 Provider·계정·모델을 직접 선택하며 자동 전환이나 자동 fallback은 하지 않는다.

### 아직 필요한 작업

- 실제 사용자 대상 사용성 검증
- 운영 서버와 데이터베이스 구축
- 정식 회원·보안·계정 복구 체계
- API Key의 운영 환경용 안전한 보관 방식
- 결제·요금제·사용량 관리
- 오류·성능·보안 모니터링
- 개인정보 처리방침과 이용약관
- 배포 환경의 CDN, HTTPS, HTTP/3 설정
- 모바일·브라우저별 회귀 테스트

## 2. 한 문장으로 설명하면 어떤 서비스인가요?

> **Think Along은 사용자가 GPT, Claude, Gemini, Grok, Kimi 등 여러 AI를 바꿔 사용해도 대화와 기억, 결정이 끊기지 않도록 이어주는 AI 생각 관리 서비스다.**

## 3. 누가 가장 먼저 돈을 내고 쓸 고객인가요?

가장 먼저 돈을 낼 가능성이 높은 고객은 **여러 AI를 실제 업무에 함께 쓰면서 모델을 바꿀 때마다 맥락을 다시 설명하는 데 불편을 느끼는 1인 창업자, 제품 기획자, 컨설턴트, 리서처**다.

### 첫 고객의 구체적인 특징

- ChatGPT, Claude, Gemini 등 두 개 이상의 AI를 유료 또는 API로 사용한다.
- 하나의 프로젝트를 며칠 또는 몇 주 동안 계속 발전시킨다.
- AI마다 대화 기록이 흩어져 결정과 근거를 다시 찾는 데 시간이 든다.
- 중요한 결정, 미결 과제, 생각의 변화를 보존해야 한다.
- 팀 협업보다 먼저 개인의 기획·리서치·의사결정 생산성을 높이고 싶어 한다.
- 반복 설명을 줄여주는 확실한 효과가 있다면 월 구독료를 지불할 의사가 있다.

### 최초 검증 권장 고객군

**여러 AI를 매일 사용하는 1인 창업자와 초기 스타트업 제품 기획자 10명**을 첫 검증 집단으로 삼는다.

## 4. 현재 단계는 어디인가요?

현재 단계는 **아이디어나 기획을 넘어선 MVP**다.

| 단계 | 상태 | 판단 근거 |
|---|---|---|
| 아이디어 | 완료 | 핵심 문제와 차별점이 정의됨 |
| 기획 | 완료 | 사용자 흐름, 화면 구조, Context·Memory 원칙이 문서화됨 |
| MVP | 현재 | 주요 화면과 다중 Provider 연속 대화가 실제 코드로 동작함 |
| 고객 검증 | 시작 전 | 외부 실제 고객의 반복 사용과 지불 의사 데이터가 아직 없음 |
| 매출 | 시작 전 | 결제 기능과 유료 고객이 아직 없음 |

정확한 표현은 다음과 같다.

> **Think Along은 핵심 기능이 작동하는 MVP를 완성했고, 이제 실제 고객 검증을 시작해야 하는 단계다.**

## 다음 단계의 완료 조건

다음 단계는 기능 추가가 아니라 **고객 검증**이다. 아래 조건을 충족하면 MVP 단계를 벗어났다고 판단한다.

- 목표 고객 10명이 실제 프로젝트를 등록한다.
- 최소 5명이 두 개 이상의 AI Provider를 연결한다.
- 최소 5명이 일주일 동안 3회 이상 다시 방문한다.
- 모델 전환 후 맥락이 이어졌다고 사용자가 평가한다.
- 최소 3명이 유료 사용 의사를 명확히 밝힌다.
- 최소 1명이 실제로 결제한다.
